# Security and privacy

This repository must never contain real patient, referrer, clinical-trial participant, donor, payment, credential, or staff-account data.

Do not paste personal or health information into GitHub issues, pull requests, Actions logs, fixtures, screenshots, or test data. Use synthetic data only.

The generated static mirror blocks forms, non-read browser requests, sensitive transaction links, analytics, and search indexing. Treat any change that weakens those controls as security-sensitive and require QEI review before deployment.

Do not mirror or publish administration panels, webmail, APIs, VPNs, staging systems, login portals, private documents, backups, or internal subdomains. Passive host discovery is filtered accordingly.

Security concerns should be reported through QEI's approved internal security process rather than a public issue.
